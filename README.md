## O que é

O PruPru.exe é um utilitário standalone (~110 KB) para Windows 10/11 com 11 ferramentas e 6 recursos extras — tudo rodando localmente, sem instalador, sem cadastro e sem coleta de dados escondida.

- Diagnóstico e Saúde do Disco
- Scanner de Segurança
- Teste de Integridade Rápido
- Backup de Configurações
- Otimizador (com Reverter)
- Limpar Espaço
- Gerenciador de Inicialização
- Desinstalador Guiado
- Foco no Jogo / Turbo de Rede / Modo Streaming

## Sobre este repositório

Aqui ficam apenas os releases publicados do executável, usados pelo mecanismo de auto-atualização do próprio app. Código-fonte é mantido internamente pela PruPru Digital Services.

## Integridade

Cada release traz o hash SHA-256 do `PruPru.exe` (disponível também via API do GitHub em cada asset). O próprio app verifica esse hash automaticamente antes de aplicar qualquer atualização — nunca substitui o executável sem confirmar a integridade do download.

## Segurança e falsos positivos

Alguns antivírus podem sinalizar o `PruPru.exe` como suspeito. Isso costuma ocorrer porque o app inclui, no seu Scanner de Segurança, uma lista de nomes de processos de mineradores de criptomoeda conhecidos — usada apenas para **detectar e alertar** sobre esses processos no seu PC, nunca para executá-los. Detalhes completos em [prupru.org/transparencia](https://prupru.org/transparencia).
